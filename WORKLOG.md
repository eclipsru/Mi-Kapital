# Рабочий журнал

Краткий журнал для продолжения разработки. Обновляйте при существенных изменениях: дата, задача, изменённые части, проверки и подтверждённый результат/неизвестный статус. Не записывайте финансовые данные пользователя, QR-коды, токены, пароли, резервные копии или другую приватную информацию. Не выдавайте предполагаемое за проверенное.

## Текущие договорённости

- Общий капитал и карточка остатка не учитывают движения по долгам. Внутренние остатки счетов могут их отражать.
- Товар, купленный «Из кармана», не меняет остаток до продажи, но учитывается в активах; после продажи цена покупки и 15% чистой прибыли поступают в остаток. Убыток и доля инвестора рассчитываются по существующим правилам. Правило уточнено пользователем после версии 2.0.46; не возвращать прежнее начисление при покупке.
- Данные ПК и Android хранятся локально и синхронизируются после сопряжения по локальной сети; для разных сетей/выключенного ПК нужен настроенный облачный сервис. Нельзя утверждать, что устройства пользователя реально подключены без подтверждения.
- Пользователю нужны понятные пошаговые объяснения и публикация обновлений после изменений. Полные инструкции для агента и выпуска — в `AGENTS.md`.

## Где искать

- Финансовая модель и вычисления: `src/core/model.ts`; экран: `src/pages/CapitalPage.tsx` и `src/components/ProductModal.tsx`; регрессии: `tests/model.test.ts`, `tests/ui.test.ts`.
- Синхронизация: `src/core/useSync.ts`, `src/core/sync.ts`, `src/core/cloud-sync.ts`, `electron/sync-server.cjs`, `src/components/SyncSettings.tsx`; тесты: `tests/sync.test.ts`. Настройки и токены пользователей не входят в репозиторий.
- Выпуск: `.github/workflows/windows.yml` и `android.yml`. Запуски: `gh run list`; текущий публичный выпуск: `gh release view`. Не предполагать успешную публикацию только по коммиту.
- Проверки: `npm ci`, `npm test`, `npm run build`. Визуальный тест `npm run visual` требует запущенного приложения; сборка в Actions запускает его автоматически. При изменении проверки UI обновлять соответствующие тесты.
