# Журнал проекта «Мой капитал»

## Состояние на 2026-11-06

### Исходный репозиторий и стек
- В исходном репозитории был только файл-заглушка `Приложение Мой капитал`; приложения, фреймворка, тестов и схемы БД не было.
- Выбран общий web UI на React + TypeScript + Vite. Для оболочек подготовлены Electron (Windows) и Capacitor (Android).
- В контейнере доступны Node.js и npm; Flutter, Dart, .NET, Java и Android SDK не обнаружены.

### Решения и предположения
- Сейчас приложение для одного владельца. Облачные записи защищены Supabase Auth и RLS, поэтому схема готова к добавлению нескольких аккаунтов.
- Валюта — RUB; деньги внутри считаются целыми копейками.
- Правило выплаты инвестору выбирается для каждого вложения: процент от прибыли, от суммы вложения, от выручки либо ручная дополнительная выплата. Капитал и дополнительная выплата отображаются отдельно; условия конкретного договора выбирает владелец.
- Потребительский долг содержит начальную сумму и журнал частичных погашений. Платёж, превышающий остаток, блокируется.
- На главной странице раздельно показаны доход от работ, выручка, результат перепродажи, затраты, обязательства инвесторам и потребительские долги.
- Без Supabase env-переменных приложение работает локально в браузере; это не синхронизируется с другими устройствами.

### Реализовано в первом этапе
- Адаптивный интерфейс и навигация: Главная, Перепродажа, Подработка с категориями, Инвесторы и Потребительские долги.
- Главная сводка за всё время, последние записи и быстрые действия.
- Формы товара, продажи, работы, ремонта авто с несколькими строками, пользовательских категорий, инвестора и потребительского долга.
- Частичные погашения долга и отметка завершённого расчёта с инвестором.
- Текстовые и голосовые описания; адресный поиск через Photon с ручным вводом.
- Supabase Auth, таблица ledger_entries, RLS, Realtime и закрытый Storage bucket для голосовых заметок (готовы миграцией; фактическое подключение к проекту ещё не запускалось).
- Electron main process, Capacitor-конфигурация и нативная папка Android. В AndroidManifest добавлено разрешение микрофона.
- Добавлен GitHub Actions workflow `.github/workflows/build-apps.yml` для сборки debug APK на Ubuntu и Windows NSIS EXE на Windows runner; артефакты публикуются на странице запуска workflow.
- `README.md`, `.env.example`, `docs/DATA_MODEL.md`, этот журнал и SQL migration.

### Проверки
- `npm install` завершился с `ELECTRON_SKIP_BINARY_DOWNLOAD=true`: установщик Electron не смог проверить сертификат при скачивании бинарника в контейнер. Electron JS package обновлён до 45.2.3; нативный Electron binary в этой среде отсутствует.
- `npm test`: 7 тестов прошли (денежный ввод, копейки, расходы/прибыль перепродажи и варианты выплаты инвестору).
- `npm run build`: TypeScript и production сборка Vite прошли.
- `npm audit --omit=dev --audit-level=high`: 0 уязвимостей в production-зависимостях. Полный аудит после обновления Electron показывает 6 умеренных предупреждений в dev/tooling дереве `electron-builder`; `npm audit fix` не устранил их без понижения major-версии builder. Вернуться к ним перед desktop-релизом.
- `npx cap add android`: native Android-проект создан. APK не собирался, так как отсутствуют Java/JDK и Android SDK.
- EXE/installer не собирался: Electron binary download завершился ошибкой сертификата; Windows installer надёжно собирать на Windows runner.
- Supabase миграция и облачные сценарии не запускались: клиентские параметры проекта не предоставлены окружению. `service_role` ключ не использовался.
