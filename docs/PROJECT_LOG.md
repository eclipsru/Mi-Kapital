# Журнал проекта «Мой капитал»

## Состояние на 2026-11-07

### Единый дизайн сайта со скриншота и удаление устаревших версий
- Весь интерфейс приложения полностью приведён к дизайн-системе и раскладке сайта со скриншота (`#0B0D11` / `#101217` / `#1A1D24` / `#171A21` / `#262B35`, оранжевый акцент `#FF8F1F`, системная типографика с табличными цифрами, без внешних шрифтов):
  - липкая верхняя шапка во всю ширину с логотипом, индикатором хранилища, строкой поиска с оранжевой кнопкой «Найти» и правым рядом значков разделов (`Главная`, `Перепродажа`, `Подработка`, `Инвесторы`, `Долги`, `Обновить`, `Кабинет`);
  - трёхколоночная рабочая область ПК (`306px` слева «В работе», широкая центральная панель со сводной шапкой, 5 счётчиками, подчёркнутыми вкладками, 4 крупными KPI-плитками, строкой фильтра/обновления и карточками записей со шкалой этапов, `306px` справа «Журнал»);
  - тёмная тема закреплена на всех уровнях (`index.html`, `src/styles.css`, `electron/main.cjs` с `nativeTheme.themeSource = 'dark'` и `backgroundColor: '#0B0D11'`, Android `Theme.AppCompat.NoActionBar`, фирменные тёмно-оранжевые иконки и сплэш-экраны).
- Удалены все следы старой бело-зелёной темы и устаревшие релизы `app-build-*`; добавлен автоматический тест-предохранитель `src/design-guard.test.ts`, блокирующий сборку при появлении светлых цветов или не-ASCII имён установщика.

### Прямое обновление из приложения (скачиваются только изменения)
- Исправлена критическая ошибка прошлых сборок, из-за которой кириллическое имя установщика обрезалось GitHub Releases до `Setup.0.2.2.exe` и ломало `latest.yml`/`.blockmap`, а тег `app-build-*` ломал поиск предыдущего `.blockmap` в `electron-updater`.
- Реализован двухконтурный механизм обновлений (`electron/updater-core.cjs`, `electron/main.cjs`, `electron/preload.cjs`, `scripts/build-update-bundle.mjs`):
  1. **Быстрый пакет изменений (`app-bundle-1.0.x.pak.gz` + `app-update-manifest.json`, ~140 КБ)** — при любых правках интерфейса и логики в чате приложение скачивает только сжатый пакет `dist/` с проверкой SHA-256 и мгновенно применяет его внутри окна без скачивания ~85 МБ Electron и без мастера установки. Обслуживание через привилегированную схему `app://mi-kapital/` сохраняет `localStorage` и сессию между любыми версиями; встроен сторожевой таймер самовосстановления (`app:boot:ready`).
  2. **Дифференциальное блочное обновление оболочки (`electron-updater` + `.blockmap`)** — при изменении самой оболочки Electron (`shellHash`) скачиваются только изменившиеся блоки `Mi-Kapital-Setup-1.0.x.exe`.
- Версия сборки автоматически увеличивается в CI (`1.0.<run_number>`, тег `v1.0.<run_number>`, `make_latest: true`).
